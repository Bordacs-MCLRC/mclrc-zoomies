# Zoomies! A Labrador Adventure

The Midland Counties Labrador Retriever Club's web game: race your Lab through five worlds and a Christmas special to win back the club's gold rosettes.

**Play:** https://bordacs-mclrc.github.io/mclrc-zoomies/

- `index.html` is the whole game (one file, no dependencies). GitHub Pages serves it.
- `source/` holds the editable source; `python3 source/build.py` rebuilds `index.html`.
- `HANDOVER.md` explains hosting, the Wix Games page, the club leaderboard and the code.
